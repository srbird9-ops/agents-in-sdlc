通过贴近现实的场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的用法。你将迭代规划变更、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为棋盘游戏提供众筹服务，整体采用开发者主题。团队的待办事项已整理成 GitHub issue，等待你着手处理。其中包括筛选和分页等功能开发，也包括无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合你开发方式的环境。每个工作坊都有自己的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能代理助手。体验 Plan 和 Autopilot 模式、说明文件、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

并行运行代理会话、切换会话模式、协作处理画布，并在桌面应用中管理 GitHub issue 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步代理、引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可体验 Copilot Chat 代理模式、MCP 服务器和自定义代理。
